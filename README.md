One honest error message a washing machine could show, entered in the [make.fun](https://make.fun/bounty/u-xvader-the-funniest-honest-appliance-error-adec4450) bounty "The Funniest Honest Appliance Error". A judge model reads the lines two at a time and picks the funnier one — the funniest honest line takes the $2 pool.

> "ERROR: Unbalanced load. I am shaking myself apart over one hoodie and a single sock. Spin cycle refused."

## Run it

```sh
python3 main.py
```

This writes the entry line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), with no trailing newline. Python 3 standard library only, deterministic — running it twice produces byte-identical output.
